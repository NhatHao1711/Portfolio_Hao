# My Website Portfolio 🚀

Trang Web Showcase tổng hợp hơn 40+ dự án Website thực tế đã triển khai (Doanh nghiệp, E-commerce, F&B, Y tế, Giáo dục, Bán lẻ, Logistics, Thời trang...).

## ✨ Tính năng nổi bật
- **Pure Showcase:** Tập trung 100% vào việc trưng bày các dự án thực tế.
- **Bộ lọc & Tìm kiếm tức thì:** Tìm nhanh theo tên, khách hàng, ngành nghề hoặc từ khóa.
- **Tone màu xanh da trời dịu nhẹ (Soft Sky Blue):** Giao diện thanh lịch, hiện đại, tối ưu trải nghiệm người dùng.
- **Liên kết thực tế:** Xem trực tiếp website đã triển khai và copy link nhanh.

## 🛠️ Công nghệ sử dụng
- **Backend:** PHP & MySQL
- **Frontend:** HTML5, Modern Vanilla CSS3 (Glassmorphism & Responsive), JavaScript (ES6+)
- **Server:** XAMPP / Apache
